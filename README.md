# GradSphere Website
Flask website: Home, About, Services, Contact, Login/Register, Dashboard.

## Run
    python -m venv venv
    venv\Scripts\activate
    pip install -r requirements.txt
    python app.py
Open http://127.0.0.1:5000

## Customize
- Text, services, stats, FAQs: `content.py`
- Colours: top of `static/css/style.css`
- Page layout: `templates/`
